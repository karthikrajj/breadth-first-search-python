📖 Algorithm Steps
  1. Choose a starting vertex.
  2. Mark it as visited.
  3. Insert it into the queue.
  4. Remove the front vertex from the queue.
  5. Add its unvisited neighbours to the queue and mark them visited.
  6. Repeat until the queue is empty.
BFS(Graph, start):
  visited = {start}
  queue = [start]

  while queue is not empty:
    vertex = remove_front(queue)
    output(vertex)

  for each neighbour of vertex:
      if neighbour is not visited:
        mark neighbour as visited
        add neighbour to queue
⚡ Complexity Analysis
Time Complexity
O(V + E)
Using adjacency list
Space Complexity
O(V)
Auxiliary space
Principle
FIFO Queue
First In, First Out
Application
Shortest Paths
Unweighted graphs

Why O(V + E)? Each vertex is enqueued and dequeued exactly once (O(V)). For each vertex, we examine all its edges (O(E) total). Combined: O(V + E).

Shortest paths: BFS finds the shortest path in terms of number of edges for unweighted graphs, because it explores vertices level by level.
